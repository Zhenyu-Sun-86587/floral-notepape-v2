# Hermes Surface Dev 1.7.2

## 本次改动

- 便签正文改为常驻 Markdown 源编辑器。点击正文直接定位源码光标，当前行显示语法标记，其他区域保持格式；Esc 或失焦后保存并恢复阅读呈现。保留选区、撤销记录，并按可见源码位置补偿滚动。
- 标题、粗斜体、删除线、行内代码、链接、引用、列表、任务和围栏代码使用编辑器装饰。公式、图片、表格和 Mermaid 复用现有只读渲染器；这是源码保留的混合编辑，不是完整 WYSIWYG。
- 保留中文输入法、格式快捷键、列表续行、Tab 缩进、图片粘贴/拖入和外部 Markdown 冲突检查。阅读时链接直接打开，编辑时用 Ctrl/Cmd+点击打开。
- 胶囊颜色使用 12 个区分度更高的槽位，旧版重复颜色做一次迁移，此后展开、隐藏和重启不重新挑色，删除会话释放颜色。超过 12 张便签时均衡复用槽位。
- 合并胶囊的拖动头位于整组前端：左右边缘在上端，顶部边缘在左端。展开后胶囊仍保留在原位，通过内部高亮反馈，不再移动拼接轮廓；单个拖出与整组拖动的外观分别处理。
- 移除原生布局补间中的固定等待，视觉过渡使用 CSS 合成。胶囊预览任务采用乐观更新，保存通知合并核对，不关闭/重建预览或重播入场动画。
