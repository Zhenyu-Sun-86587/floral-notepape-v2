# 笺影 Mac 2.0.4：原生材质兼容

基线 main `3a3006c`，本机原安装 2.0.3。原生材质的背景已经有系统回退，但部分动画和桌面折射入口只判断保存的偏好，设置栏也按偏好显示玻璃控件。本轮统一为实际材质可用性判断。

- 关闭“Mac 原生材质”：不创建玻璃或磨砂背景，不启动玻璃融合、回弹和桌面折射。AppKit 标题/操作栏、圆角边界、拖动、锁定与正文保留。
- 开启：系统同时提供 NSGlassEffectView 和 NSGlassEffectContainerView 时保留现有液态玻璃效果；缺少这些公开类时采用 NSVisualEffectView 磨砂。系统“减少透明度”时采用实体背景，停止玻璃专属动态效果。
- 设置栏查询系统能力，旧系统显示磨砂浓度并禁用玻璃选项；关闭原生材质时禁用材质参数和动画控件。保存的玻璃浓度、效果档位及折射偏好不被清空，重新开启后恢复。
- 原生标题栏位于 WebView 外，关闭材质时 DOM 的实体背景无法覆盖它。本轮只在关闭原生材质时增加系统色实体背景，避免标题区露出桌面；开启时移除该背景，完整保留 2.0.3 的透明标题栏与玻璃/磨砂效果，不增加标题衬底。
- 材质层与 Wry 正文的固定 clip 所有权保持独立，不改变内部或外部 Markdown 的保存、绑定、共享选择和小组件编号。Mac 命令与实现保持平台编译隔离，Windows 实现未改。

正式应用和 WidgetKit 扩展最低 macOS 15，本轮兼容指 macOS 15–25 回退磨砂，macOS 26+ 使用可用的玻璃；不宣称支持 macOS 14 或更早版本。

## 验证边界

使用现有 GitHub Actions Mac 完整 Xcode 构建和 Windows 兼容检查，不新增本机动态测试或界面操作。未在旧版 macOS 真机验证视觉效果，未测量 CPU、内存、GPU 或能耗，不宣称量化性能提升。人工验收：关闭/开启材质后便签与胶囊正文、标题栏、拖动、合并分离及回弹；旧系统磨砂；内部与外部便签各一份。

安装前保留旧应用和当前真实数据备份，校验安装包、身份、版本、嵌入扩展和严格签名；只终止本项目进程并替换 /Applications/Folio.app。按要求不启动新版做本机运行测试。ad-hoc 签名且未公证，升级可能需要重新授权；不保证永久免授权或跨机器全部可用。私有容器 WidgetKit 路线保持。
