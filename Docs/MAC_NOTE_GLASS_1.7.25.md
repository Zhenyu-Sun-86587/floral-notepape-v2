# Mac 1.7.25：便签三档玻璃

1.7.26 小改动：Mac 正文阅读层不再通过单击绕过“双击文字区域进入编辑”设置。开启设置时双击进入编辑并定位源码光标；关闭时正文点击不进入编辑，仍可用原生铅笔按钮。Windows 单击逻辑保留。人工检查正文单击选择、双击编辑、链接和任务复选框。

便签背景现在可以独立选择轻量、弹性或流体档位。胶囊与便签分别配置，不会因为胶囊开启最高档而增加全部便签的开销。既有轻量效果和默认值保留；磨砂材质继续使用原生实现。

## 背景与文字

弹性与流体档把 AppKit 玻璃背景和前景内容分开。标题栏仍为原生 AppKit，Markdown/编辑区仍为 WKWebView，文字保持原分辨率，选择和输入区域不随背景弹跳。标题不可选，拖动标题时用 Core Animation 弹簧反馈背景，释放后恢复。没有新增对展开、收纳过程的整窗形变。

流体档使用共享 ScreenCaptureKit 流和 Metal 纹理，在便签边缘产生折射和光感；正文区域只做轻微扩散以保留阅读稳定性。不新增实线描边，背景覆盖整个便签。它不是 Apple iOS 原生液态玻璃的逐像素复现。

## 性能边界

- 便签稳态背景最高 12fps、渲染纹理最长边 768 像素；前景文字不降低分辨率。
- 同一物理显示器共享一个屏幕采样流：仅便签时 12fps，有胶囊时最高 24fps。胶囊与便签复用 GPU 管线与纹理。
- 背景按屏幕新帧更新；拖动与缩放还用原生窗口通知刷新已有纹理，不为每个窗口新增轮询。
- 流体窗口隐藏、最小化或不在当前 Space 时不绘制；没有可见流体窗口时停止屏幕采样。存在流体窗口时用每秒一次的生命周期检查恢复可见窗口采样；全部移除后取消检查。
- 屏幕配置变更重建捕获，失败后间隔至少 15 秒重试，手动授权/重试可以立即重试。

流体档仍比原生轻量档消耗更多 GPU，尤其是多张大便签。本轮没有进行耗电或帧率基准测试。

## 授权与平台

最高档需要用户授予 macOS 屏幕录制权限。未授权、捕获失败或 GPU 初始化失败时保留原生玻璃背景，不阻断编辑。排除本应用窗口，避免递归画面；不采集音频，不保存或上传屏幕帧。

设置和实现仅在 Mac 平台编译，Windows 胶囊、便签和设置未修改。

## 基础检查与人工验收

基础检查：两个 Metal 离屏测试验证胶囊与便签透明角和主体覆盖；两个 Mac 配置测试验证旧配置兼容和独立档位；前端 lint、Mac 与 Windows 平台前端构建。

人工检查：分别切换便签的三档；流体档授权后观察整个便签背景、正文清晰度和边缘；拖动标题、调整窗口大小、编辑和选择正文；切换 Spaces、最小化和恢复；打开多张便签观察流畅度与能耗。特别确认磨砂与已有轻量档的行为正常。
