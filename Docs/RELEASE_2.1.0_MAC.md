# 笺影 Mac 2.1.0：原位编辑、三种 Markdown 显示与性能加固

## 基线与范围

发布基线 main `5c5be65` / 2.0.8；集成 PR #26 的 `c0debaa3a9b52e51b286765e2839890fb4b3234f`，保留原提交记录。原分支起于 2.0.5，集成后保留 2.0.6–2.0.8 的窗口完整尺寸、WidgetKit 容器诊断及 macOS 27 超大竖排。

新增可选桌面便签原位编辑；源码／混合／预览支持全局默认与逐便签覆盖，胶囊共享设置。胶囊悬停保持只读；新增外部 MD 图片粘贴、明确的文件冲突处理、原生菜单撤销和标题栏配色。test-app 原实现保留，不作为本次改造目标，正式构建不启用其 feature/config。

菜单栏继续使用原百合花图标，仅在 macOS 设置 AppKit template 着色，由系统选择黑色、白色和选中状态；未替换图案，Windows 保持原图标。

## 性能和数据修复

- 常驻 CodeMirror 保留文档、选区和撤销历史；完整 Markdown 阅读树只在实际阅读时挂载，阅读时停用隐藏编辑器的复杂块渲染。混合模式避免隐藏完整预览与局部公式／图表同时渲染。
- 装饰按顶层 Markdown 块缓存。选区变化仅重建受影响块，文本变化映射并复用未变块，避免每次移动光标都拼接全文、遍历所有语法节点及重新排序全部装饰。仍扫描顶层块索引；单个巨大段落／列表的重建成本仍与该块大小有关。
- 引用定义按块缓存。定义变化会使依赖呈现失效；后台语法解析完成、只读状态切换、IME／指针冻结后的正文变化会保守重建，优先正确性。缓存仅属于当前文档，不积累历史全文。
- 局部 widget 比较明确字段，去掉更新路径中的 JSON 序列化；既有 ResizeObserver 与 React root 销毁路径保留。
- 源码位置映射在 DOM 中采用等差区间压缩；保留实体、转义和代码行的精确映射，避免长代码块写入逐字符 JSON 属性。
- 内部和外部图片插入接入保存屏障：关闭、收纳、切换、更新／退出准备等待插入完成，再保存最新正文。失败可阻止继续关闭，避免孤立图片文件和丢失引用。显式冲突处理等待已有图片操作后再锁定编辑器。
- 任务事务明确登记原生历史目标，阅读态首次勾选即可通过原生撤销路由恢复，无需先进入编辑；锁定与组合输入限制保留。

## 性能证据与限制

复现：`node scripts/benchmark-inline-layout.mjs`。脚本通过 git 读取固定 PR 基线；只使用合成文本和 CodeMirror 状态，不启动应用、不读取真实笔记。原始结果输出 `local-build/Folio-2.1.0-performance.json`。

机器：Apple M4 / 16 GB，macOS 27.2，arm64，Node 26.10.0。文档 55,888 字符、1000 段。模块、语法树和首个布局预热后，各场景 50 次操作，5 轮交替先后顺序，取总耗时中位数。

| 场景                        | PR 原实现 | 2.1.0 优化实现 |
| --------------------------- | --------: | -------------: |
| 50 次选区变化               | 110.72 ms |       10.27 ms |
| 50 次文本插入（含状态更新） | 126.25 ms |       26.01 ms |

这些是 CodeMirror 状态／装饰微基准，不是整应用性能提升、真实按键延迟或持续 CPU。未测冷启动、实际 WebView／DOM／Mermaid 绘制、多窗口 RSS、后台唤醒、GPU、能耗及长时间运行。无界面回归确认混合模式仅保留一份公式渲染，普通预览禁用隐藏复杂块；不能替代实际排版验收。
