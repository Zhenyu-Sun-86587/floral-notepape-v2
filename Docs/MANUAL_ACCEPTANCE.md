# 首轮人工验收

使用虚构测试目录，不选择原版花笺数据或真实同步目录。Windows 安装包位于 `src-tauri/target/release/bundle/nsis/`。先核对应用显示名为 Hermes Surface Dev，原版仍可独立运行。

1. 新建中文笔记，输入、撤销/重做、保存；关闭并重新打开确认正文与标题。
2. 同时打开两篇笔记，交替编辑并保存，确认内容没有串写。
3. 在编辑/预览/磁贴模式间切换，拖动与四角缩放；关闭后从托盘及原有快捷入口再次打开。
4. 编辑未保存内容时关闭便签或退出，确认内容已保存，或明确提示保存失败。
5. 准备一份测试用 `.md` 文件。在主界面点击“导入 Markdown”，编辑并保存导入后的笔记；确认原文件不变，笔记数据目录中的副本已更新。另将该文件从资源管理器拖入主窗口，编辑并保存；确认“外部文件”列表中的内容写回原文件。两条入口分别记录结果，不要把导入视为直接编辑原文件。
6. 分别记录仅托盘、1 张磁贴、3 张磁贴、全部关闭和退出后的窗口数、应用主进程及其 WebView2 子进程的 Working Set 与 Private Bytes。P0 对照构建需使用相同笔记、Release 设置和测试目录；未实测项保持“未测”。
7. P3：在仓库外虚构目录创建 `Today.md`，点击“绑定 Markdown 目录”，确认其出现在外部文件列表。选择该文件并钉屏；在磁贴右键菜单选择“转为小窗”，编辑并保存，确认原文件变化。关闭管理窗口后仍应能编辑磁贴。
8. 使用另一程序对 `Today.md` 做同路径原子替换，确认对应便签刷新；本地有未保存输入时，确认出现冲突选择且不会覆盖输入。新增 `.md` 应进入列表但不自动弹窗；解绑一个扫描文件、重新扫描及重启后仍应排除。分别试默认非递归与“含子目录”，并核对 UTF-8 BOM、CRLF 文件写回格式。
9. P4：在外部 `.md` 文首加入完整 YAML Frontmatter，后接正文分隔线、两条文字相同的任务和一段 `js` 代码；预览应隐藏 Frontmatter、保留正文分隔线并高亮代码。勾选第二条任务后查看原文件，确认只改第二个 `[ ]`。
10. P4：在绑定目录内放 `docs/Today.md` 与 `assets/a.png`，以 `../assets/a.png` 引图；预览应显示本地图片。再试越出绑定目录的图片路径，预览不得加载。远程 HTTPS 图片默认不显示，开启“允许远程图片”后才显示。
11. P4：加入 `mermaid` 代码围栏并切换预览，确认正常图表显示；输入错误图表时应只在该图表位置看到源码与错误。编辑有序/任务列表后按 Enter，确认新项继续且新任务未勾选；空项按 Enter 应结束列表。在主编辑器和独立便签中选中文字后试 Ctrl+B、Ctrl+I、Ctrl+K。
12. P5：切换浅色、Tokyo Night 和 Everforest，观察正文、预览、代码、Mermaid 与菜单；设置全局字号后只给一篇便签改字号，继续改全局颜色，确认该便签颜色仍跟随。选择本地便签背景图，调整图片模糊和背景透明度，文字应保持清晰；开关 Windows Acrylic 时观察主窗口的冷色半透明标题栏/侧栏与实心正文区，并把它和用户提供的 Obsidian 参考图对比。再观察独立便签是否真的透出并模糊桌面；重点看四角是否有矩形底层、白边或原生标题栏痕迹，在桌面和主窗口上方分别观察，并试一次缩放。状态文字只表示系统接受请求，不能代替视觉验收。关闭重开应用后确认设置保留，期间保存与外部文件监听仍正常。主题 JSON 导出再导入应还原可移植字段，本地背景图片不随主题文件导出。

不要把 `--silent` 的隐藏主界面写成已完成的边缘收纳功能。
