# macOS 原位编辑：实现与验证

本改动基于 floral-notepape-v2 2.0.5，保留 Tauri、React、CodeMirror、MarkdownSurface 双层协调和原有存储协议。版本号未变更。2026-10-08 已按用户要求安装独立的 `/Applications/folio(test).app`，没有覆盖原应用。当前代码供审查；完整的胶囊悬停与输入法真机验收尚未完成。

## 如何自己测试（2026-10-08）

在 Finder「应用程序」打开 **folio(test)**，也可用 Spotlight 搜索此名称。已配置独立 identifier `dev.hermes.surface.inline-test`、URL scheme `folio-test`，无需通过终端设置环境变量。

测试数据位于 `~/Library/Application Support/folio-test/`，其中 `config` 和 `data` 与原版隔离。保留之前测试入口的数据副本，另外添加「Markdown 分类测试」下的 21 篇示例，图片示例含真实本地 SVG 和缺失图片。旧 `.command` 入口也已改为打开安装的测试应用。

1. 设置中找到「原位编辑（桌面便签与胶囊）」；这个测试环境已开启。代码对缺少此字段的既有配置默认关闭，避免升级时强制改变原行为。
2. 选中示例，点击「钉到屏幕」打开桌面便签，在正文中点击、输入、撤销；用便签顶部收纳按钮测试胶囊。
3. 胶囊悬停面板中点击正文或铅笔，直接编辑；关闭开关后，正文恢复阅读，铅笔恢复展开编辑。编辑中的胶囊会话保留到正常结束，关闭开关不会丢弃草稿。
4. 保存、关闭再打开，确认内容保留。绑定文件示例只指向测试目录中的 `external.md`。

这里的桌面测试对象是「钉到屏幕」的应用便签窗口。当前测试包未包含系统 WidgetKit 扩展，也没有对系统桌面小组件宣称编辑或验收通过。

## 2026-10-08 点击偏移修复

已在浏览器中复现：点击三级标题，字符却插入四级标题。原因是 `.cm-live-heading` 的垂直 margin 不属于 CodeMirror 测量的行盒；改为 padding 后恢复正确的坐标命中。安装版 WKWebView 中也完成了滚动后点击三级标题、插入并撤销的实测。

分类测试另外发现阅读层对引用续行、实体、转义、代码和提示块会回退到段首。现在记录渲染文字到原始 Markdown 的 UTF-16 边界映射，代码保留字面量，提示块移除标记时同步修正 AST 位置。表格 widget 使用相同映射定位单元格。Frontmatter 和提示块也接入局部呈现。

浏览器回归使用 `npm run dev -- --host 127.0.0.1` 后打开 `/scripts/inline-editing-qa.html`；页面使用生产的 MarkdownSurface/SourceEditor，底部展示原文，便于复核每次插入位置。共 41 个坐标检查通过：普通文字、标题、强调、列表、引用、行内代码、任务、转义、Setext 标题、换行、图片后的文字、公式后的文字、表格单元格、Mermaid 后文字、分割线、提示块、Frontmatter、HTML 字面量、脚注正文、编辑态链接，以及长文滚动后的阅读/编辑落点。图片这组浏览器测试覆盖禁用图片占位后的坐标；安装版另实测了本地 SVG 在主界面、桌面阅读及编辑态加载，图片后插入文字及撤销均保留图片；缺失图片保持占位。

## 可见变化

- Mac 桌面便签单击普通文字即在原窗口编辑。双击正文交给选词，开启原位编辑后隐藏双击编辑设置；关闭后恢复原设置，其他平台保留原行为。
- 编辑中保留标题、强调、列表、引用、代码等排版；光标或选区涉及的语法范围才展开标记。图片、表格、公式和 Mermaid 使用已有渲染器，编辑时展开对应范围。
- 胶囊内容面板的正文和铅笔直接进入面板内编辑。展开按钮仍打开独立便签。
- 胶囊编辑期间固定当前笔记；鼠标移开不自动隐藏，也不因经过其他胶囊换篇。关闭、展开、隐藏、系统关闭窗口和全局显隐先处理当前保存。
- 内部笔记按 updatedAt 保存；外部文件按 revision 保存并保留 linked 草稿。失败显示重试保存、重新加载入口，重新加载须明确放弃草稿。关闭自动保存时，显式离开提供保存、放弃、取消。
- 任务修改、撤销、Cmd S、图片粘贴/拖入接入当前编辑会话。外部文件的粘贴图片保存为原文件同目录的唯一文件名，Markdown 使用相对路径。

## 代码边界

`SourceEditor` 增加可选 live presentation，默认仍为 source。Lezer 范围装饰不修改原文；任务 widget 派发单字符事务。`MarkdownSurface` 保留常驻编辑器和阅读快照，接收宿主滚动容器。图片的异步插入位置随事务映射，并核对文档和编辑器身份。

打包后的 Tauri 页面含 style nonce，CodeMirror 动态样式沿用该 nonce；`capsule.html` 提供静态样式锚点。实际窗口检查发现并修复了未传 nonce 时行内内容异常换行的问题，未放宽 CSP。

`useCapsuleEditing` 仅管理胶囊宿主的加载、草稿、有序保存和离开确认。`useCapsulePreview` 在编辑占用期间推迟预览刷新，避免覆盖草稿。原生编辑占用与鼠标选择占用独立，绑定 key/generation；离开确认还需匹配 requestId。过期确认、取消、失败和超时均不隐藏编辑内容。

`macos_lifecycle` 与更新安装沿用原有准备保存协议。胶囊等待组合输入、图片操作和保存队列后报告结果；取消退出或安装失败解除输入冻结。胶囊插件权限仅新增到 capsule-preview，未扩大边缘胶囊条权限。

## 合并前仍需完成

自动测试不能证明真实拼音候选、鼠标悬停与 WKWebView 几何体验。当前 GUI 自动化只完成普通便签路径；它无法可靠选择非激活的胶囊预览窗口，因此不能把胶囊完整交互记为真机通过。

1. 胶囊内点击文字/铅笔，确认不展开独立便签；移出鼠标、经过另一胶囊仍能继续输入。
2. 拼音候选期间的 Cmd S、Esc、关闭、切换应用；结束组合输入后不丢字、不提前收起。
3. 内部便签与绑定 Markdown 分别验证保存、重开、外部冲突、保存失败、系统 Cmd W、Cmd Q，以及更新安装取消后的继续输入。
4. 图片加载/粘贴、表格、公式、Mermaid、跨段选区和 1 万/10 万字符长文的实际滚动与落点；跨屏和不同缩放。
5. Intel Mac 与 Windows 原生构建/运行回归，以及普通便签和胶囊的交互对比录屏。

这些是尚未完成的验收项，不是已经通过的测试结论。本次没有发布版本，也没有替换用户原有应用；已安装独立测试应用。
