- Mac 桌面便签单击普通文字即在原窗口编辑。双击正文交给选词，开启原位编辑后隐藏双击编辑设置；关闭后恢复原设置，其他平台保留原行为。
- 编辑中保留标题、强调、列表、引用、代码等排版；光标或选区涉及的语法范围才展开标记。图片、表格、公式和 Mermaid 使用已有渲染器，编辑时展开对应范围。
- 胶囊内容面板的正文和铅笔直接进入面板内编辑。展开按钮仍打开独立便签。
- 胶囊编辑期间固定当前笔记；鼠标移开不自动隐藏，也不因经过其他胶囊换篇。关闭、展开、隐藏、系统关闭窗口和全局显隐先处理当前保存。
- 内部笔记按 updatedAt 保存；外部文件按 revision 保存并保留 linked 草稿。失败显示重试保存、重新加载入口，重新加载须明确放弃草稿。关闭自动保存时，显式离开提供保存、放弃、取消。

## 代码边界

`SourceEditor` 增加可选 live presentation，默认仍为 source。Lezer 范围装饰不修改原文；任务 widget 派发单字符事务。`MarkdownSurface` 保留常驻编辑器和阅读快照，接收宿主滚动容器。图片的异步插入位置随事务映射，并核对文档和编辑器身份。

打包后的 Tauri 页面含 style nonce，CodeMirror 动态样式沿用该 nonce；`capsule.html` 提供静态样式锚点。实际窗口检查发现并修复了未传 nonce 时行内内容异常换行的问题，未放宽 CSP。

`useCapsuleEditing` 仅管理胶囊宿主的加载、草稿、有序保存和离开确认。`useCapsulePreview` 在编辑占用期间推迟预览刷新，避免覆盖草稿。原生编辑占用与鼠标选择占用独立，绑定 key/generation；离开确认还需匹配 requestId。过期确认、取消、失败和超时均不隐藏编辑内容。

`macos_lifecycle` 与更新安装沿用原有准备保存协议。胶囊等待组合输入、图片操作和保存队列后报告结果；取消退出或安装失败解除输入冻结。胶囊插件权限仅新增到 capsule-preview，未扩大边缘胶囊条权限。

## 三种显示方式（2026-10-08）

Mac 设置新增“默认显示方式（桌面便签与胶囊）”：

- 源码：正文和 Markdown 标记均按纯文本显示。
- 混合：文字语法标记保留并淡化，同时显示标题、强调、引用和代码格式；图片、任务、表格、行内/块级公式、Mermaid、分割线和提示块渲染显示，编辑对应复杂内容时展开其源码，离开后恢复。普通代码保留围栏；Frontmatter、脚注定义及 HTML 字面量保持可编辑原文。
- 预览：使用原有 Markdown 渲染；开启原位编辑时，编辑中的局部范围显示语法。

桌面便签的原生顶边条、胶囊预览标题栏均提供一个模式图标按钮，点击按源码 → 混合 → 预览 → 源码循环。单张便签的选择在桌面窗口和对应胶囊之间共享，重开后保留；未单独选择的便签随设置默认值更新。显示方式与原位编辑开关独立：关闭原位编辑仍保留原有编辑入口，锁定便签可以切换显示但不能写入正文。macOS 统一使用三种显示方式设置，旧的 `tileRenderMarkdown` 字段仅保留为兼容默认值；Windows 继续使用原有 Markdown 渲染开关。

实现保留现有 CodeMirror + MarkdownPreview 架构。源码/混合阅读时显示同一个只读 EditorView；预览继续使用渲染层。混合文字装饰只加样式；图片用范围装饰呈现，不改写源文档。切换不改写 Markdown、不重建 EditorView、不清空撤销历史，组合输入期间推迟显示切换。

## 2026-10-14 胶囊内部图片修复

用户反馈同一张粘贴图片在主编辑器可见，胶囊却显示“图片路径不可用”。Rust 的内部便签 CapsuleEntry 将 imageBaseDir / imageRootDir 序列化为 null；胶囊已对 base 做回退，但将 root 的 null 原样传给渲染器，导致 JavaScript 默认参数不能回退到 base，路径被拒绝。

现在 CapsuleEntry 类型准确声明 null，并在胶囊到渲染层的边界将缺省 root 归一化为 undefined。内部图片沿用数据目录；外部文件继续使用绑定目录边界，不放宽目录范围。

新增 Preview.images.test.tsx 使用真实 MarkdownPreview 渲染胶囊（不 mock 渲染组件），复现 null 路径字段和 images/<note-id>/<image-id>.png。旧代码下内部图片测试失败，修复后通过；同时检查外部相对图片和越界拒绝。独立测试应用已重新打包、安装并验证本机签名，未修改笔记或图片数据。此处组件测试不代表真实胶囊悬停窗口已完成像素验收。
