# Mac 1.7.23 / 1.7.24：三档玻璃与真实桌面折射

最终包为 1.7.24：补齐流体状态接口在命令注册处的 Mac 编译标记。1.7.23 为本轮初始构建，Mac 渲染效果相同。

用户授权最高档读取真实桌面，接受系统屏幕录制权限和更高 GPU 开销。三档设置仅进入 Mac 编译：轻量（旧效果/默认）、弹性玻璃（原生玻璃）、流体玻璃（最高/实验）。旧配置与已选档位保留，不自动切到最高档。

## 实现

- 弹性档增加按下收缩与松手原生 CASpringAnimation 回弹，快速重复操作从当前呈现状态衔接。系统减少动态效果与关闭融合动画均抑制该反馈。
- `native/FluidGlass.swift` 独立负责 ScreenCaptureKit 采样、Metal 纹理与视图生命周期；Rust 仅通过主线程 FFI 接入。build.rs 只在 Mac 目标编译该模块；Windows 不编译 Swift，不增加其设置。
- 最高档以相邻圆形的平滑距离场构造液滴，边缘方向性高光与透镜偏移采样真实背景，没有实线描边。按下与松开采用阻尼形变；融合/分离在单个临时场景中插值圆心与半径。不是完整流体力学模拟，不保证复刻 iOS 演示。
- 同一显示器共享采样流，24fps、最大输出宽度 1600 像素、队列深度 3；局部动画最高 60fps。单组超过 12 个成员回退原生玻璃，跨窗口过渡仍限制 640 点范围、约 480ms。
- 排除整个本应用以避免递归采样，因此本应用主窗口/便签也不进入折射纹理；不采集音频/麦克风，不保存、上传或记录画面。GPU 完成前保留对应像素缓冲，之后释放。切档、退休窗口、准备失败、流体过渡结束都会清理对应视图；无使用者时停止采样。
- 权限缺失、采样失败或 Metal 不可用时显示原生弹性背景。设置显示运行状态，并提供“授权 / 重试背景采样”。屏幕录制权限由用户完成，系统要求时需重启应用。

最高档即使没有交互，也需要采样可见背景。相比前两档有持续采样与 GPU 开销，尚无耗电、GPU 占用或温度基准。减少动态效果只抑制形变，不停止最高档的背景采样；切回低档才停止采样。

## 基础验证与人工验收

离屏 GPU 检查验证 Metal 着色器在本机编译并绘制：外部透明、两个液滴连接处有实体玻璃；该检查不启动屏幕采样或申请权限。另检查配置兼容、动画有限形变与归位、前端构建及安装包构建。

本轮 GPU 1 项、Mac 配置 2 项、动画 3 项检查通过；lint、Mac 和 Windows 前端构建通过。实际屏幕授权、采样纹理正确性和最终视觉没有由离屏检查覆盖。

人工操作：设置 → Mac 原生材质 → 胶囊动态效果 → 流体玻璃（最高/实验），保存后点击授权/重试。在系统提示中授权，必要时重启。观察真实背景是否随窗口变化更新、镜面偏移、无实线边缘、按下回弹、拆分融合、快速切档、多显示器/Spaces、没有递归画面或残留。未授权回退、耗电与最终视觉需实机确认；构建/GPU 烟测不替代这些验收。
