# 1.7.0 便签与胶囊交互契约

会话键仍为 `note:<uuid>` 或 `linked:<uuid>`；本机 `surface-sessions.json` 保留原有窗口标签、位置、绑定和启动策略。`presentation` 只负责 `expanded`（展开）、`stored`（边缘胶囊）、`hidden`（关闭桌面入口）。读写状态是展开窗口的运行时状态，不写入会话。普通关闭不删除内容或外部绑定。

| 入口                          | 动作                                                                                                                             |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 阅读便签正文单击              | 延迟判别单击后，在原窗口进入写作；链接、任务、工具、拖选和双击仍执行原行为。                                                     |
| 写作便签 Esc / 离开窗口工作区 | 先保存，成功后回阅读；失败保留编辑器。Ctrl/Cmd+S 仅保存。                                                                        |
| 胶囊悬停                      | 按需显示共享预览；胶囊、预览和短暂跨窗间隙属于同一交互过程。                                                                     |
| 胶囊单击 / 真正拖动           | 单击直接展开原窗口；超过阈值后才移动胶囊，拖动结束不展开。                                                                       |
| 胶囊右键                      | 原生菜单可展开、编辑或关闭所选成员；关闭只改为 `hidden`。                                                                        |
| 预览正文 / 标题与按钮         | 正文可选、复制、滚动和勾选任务；标题与展开按钮恢复便签，编辑按钮恢复后进入写作。预览 X 仅关闭预览。                              |
| 单便签快捷键                  | `hidden`/`stored` 时展开；展开但未活动时显示并聚焦；活动时按 `shortcutToggleAction` 收回胶囊或关闭桌面入口。旧会话默认 `store`。 |

胶囊颜色键首次收纳时写入会话，之后换边、排序、合并或重启不重分配。各成员始终有独立 key、快捷键和关闭动作。预览内容只读前 60 行/2400 字符，截断时有提示；任务勾选通过既有源位置补丁及对应内部/外部保存通道写回。Windows 原生窗口承载与 Mac 能力边界见 [MAC_HANDOFF.md](MAC_HANDOFF.md)；人工验收见 [MANUAL_ACCEPTANCE.md](MANUAL_ACCEPTANCE.md)。
