# 笺影 Mac 1.8.0 阶段封盘

本轮为 Mac 原生交互与材质阶段的基线，不代表所有视觉问题已被人工验收。后续开发以此版本为起点。

## 身份与数据

Mac 显示名为「笺影」，底层产品/安装文件名为 Jianying，包为 Jianying.app。Rust 可执行文件 hermes-surface-dev、bundle ID dev.hermes.surface、英文配置与数据目录继续保留，避免改变存储与权限身份。Windows 产品名与实现不变。Mac 产品名通过 tauri.macos.conf.json 覆盖，CFBundleDisplayName 使用独立 Info.plist。

## 设置的明确含义

- 全局材质：液态玻璃 / 磨砂；关闭原生材质则使用既有界面背景。
- 各窗口背景浓度：调整染色与底层扩散，不承诺控制 Apple 原生折射强度。磨砂则调整不透明度。
- 便签、胶囊分别选择：系统原生玻璃 / 桌面折射（实验、较高开销）。移除容易混淆的三档展示。
- 动画独立控制：便签拖动回弹、胶囊融合与按压动画。磨砂时便签回弹不运行；系统减少动态效果继续优先。
- 桌面折射强度：0–100%，只控制自定义 shader 的边缘位移，便签与胶囊共用；0 仍采样，停采样需切回原生背景。
- 桌面折射节能模式：便签稳态 6fps、最长边512像素，胶囊采样12fps、按压/合并动画30fps。标准保留便签12fps/768像素、胶囊采样24fps、动画60fps；便签按压短时分别12/24fps。

旧 lightweight / elastic / fluid 配置继续读取，无破坏迁移。新 noteSpring 可独立覆盖回弹；没有该值时沿用旧档位的动画习惯。不会自动更改用户的材质、折射或节能偏好。

## 性能整理

检查了背景渲染、设置保存、胶囊刷新、原生标题和正文编辑链路。本轮定位并修改：

1. 改便签浓度、回弹、折射预算或普通设置不再重建所有胶囊；只有胶囊材质、浓度、模式或动画变化才刷新胶囊。
2. 折射强度/预算直接更新现有 Metal 视图与采样流，不重建窗口或编辑器。
3. 屏幕回调只处理当前 Space 的可见、未最小化、未暂停视图，不再提前显露隐藏 Metal 层。
4. 合并动画增加0.7秒停止兜底，释放形变数据；按压动画已有同等停止机制。
5. 设置中的状态查询由2秒降为5秒，设置页面不可见时停止查询；关闭折射或材质后不查询。
6. 所有便签玻璃都与正文分层，避免轻量模式仍把正文放在玻璃强调树里，减少焦点引起的材质差异。

沿用同屏共享捕获、CVMetalTextureCache 纹理复用、GPU 完成前保留帧、静止时按新帧绘制、不可见窗口停止绘制、无可见折射窗口停采样。生命周期检查为每秒一次，全部折射视图移除后取消。编辑器常驻 EditorState，编辑期间不运行 Markdown/KaTeX/Mermaid 预览重渲染；没有扩大修改正文编辑架构。

以4:3便签计算，节能背景512×384×6约118万像素/秒，标准768×576×12约531万像素/秒：背景像素预算降低约78%。这是理论渲染量，不能等同于 GPU 占用或耗电下降78%。没有实际耗电或帧率基准测试。

## 基础检查与人工收尾

基础：Metal 胶囊/便签离屏测试，旧配置与独立回弹/节能配置兼容测试，原生名字/菜单测试，既有正文与双击策略测试；lint 与 Mac/Windows 前端构建。Mac 安装包编译并验证版本、启动进程和远端资产哈希。

人工：原生与桌面折射切换、磨砂/浓度、折射强度、节能开关；正文单击选字/双击编辑、保存、链接和任务复选框；胶囊单击收放、悬停预览、拖动合并分离；多便签、切换 Space/全屏/外接屏、隐藏恢复、锁定解锁；授权回退及多窗口耗电。iOS 液态玻璃并非逐像素一致，原生折射强度由系统控制。

安装替换旧 app 和已校验的旧 DMG，旧版移入废纸篓，笔记与配置不清理。本封盘记录不替代上述人工验收。
