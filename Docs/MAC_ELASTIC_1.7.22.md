# Mac 1.7.22：可选弹性玻璃

用户希望玻璃更接近 iOS 的清透与 Q 弹，并要求把开销较高的效果做成设置选项。Mac 材质设置增加“胶囊动态效果”：轻量（当前效果）/弹性玻璃。默认轻量，旧配置缺省仍为轻量；保留原融合动画开关、玻璃浓度和磨砂参数。Windows 设置与实现不变。

弹性档继续使用公开 NSGlassEffectView / NSGlassEffectContainerView。减少胶囊白色染色，让系统绘制折射与边缘，不增加描边；玻璃轮廓不再被额外的圆角矩形裁切。融合过渡统一使用单张 40 点、多成员 44 点的玻璃形状，不再用图标大小的玻璃块。

融合/分离采用 0.24 + 0.10 + 0.14 秒的三段原生动画：沿移动轴拉伸、有限过冲、反向回弹、归位。玻璃容器根据相邻形状的距离融合。过渡期间只暂停最终窗口的装饰玻璃，不隐藏真实窗口或按钮；临时背景放在真实窗口下方，不复制文档图标。完成、取消或切换设置都恢复背景。

## 开销与能力边界

这是短时形变动画，不是持续流体模拟，也没有自定义桌面采样或折射着色器。每次最多 12 个成员、640 点范围、一个临时背景窗口，约 480ms 后清理；空闲时无动画循环。较轻量档动画时间更长，交互时合成开销增加，尚无 GPU/耗电基准数据。系统减少动态效果或关闭融合动画时不运行。原生光学效果由 macOS 控制，无法承诺和 iOS 演示逐像素一致。

参考：[Apple WWDC25 AppKit 原生玻璃与距离融合](https://developer.apple.com/videos/play/wwdc2025/310/)。

## 人工检查

1. 设置 → Mac 原生材质 → 胶囊动态效果，切换轻量/弹性；重启后选项保留。
2. 弹性档融合与拆分，观察整体形变、回弹、边缘及通透度；检查结束后背景恢复，图标不重影。
3. 连续快速融合、取消拖动、动画期间切换材质或关闭动画，检查没有残留窗口和空白背景。
4. 对比玻璃浓度、磨砂及不同桌面背景，评估可读性和视觉偏好；关注操作期间流畅度。

本轮不扩大修改悬停预览焦点行为。

基础验证：动画成员识别、有限形变与精确归位共 3 项，以及配置兼容/往返序列化 2 项通过；lint、Mac 与 Windows 前端构建通过。视觉一致性与实际 GPU/耗电开销仍需人工对比，不据此声明达到 iOS 演示效果。
