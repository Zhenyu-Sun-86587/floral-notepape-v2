# Hermes Surface Dev 1.7.0

本次 Windows 版本整理了便签和胶囊的交互：

- 阅读便签单击普通正文即可在原窗口写作；Esc 或离开工作区时保存并返回阅读，保存失败时保留编辑内容。
- 胶囊单击直接展开、右键可编辑或关闭所选便签；收纳、关闭和删除保持独立。每个胶囊的颜色身份持久保存，按下不会使拼接轮廓临时拆开。
- 共享预览允许跨窗口移动、滚动、选择复制和勾选任务；正文复用既有 Markdown 与原文件保存通道。
- 单便签快捷键可选择再次触发时收回胶囊或关闭桌面入口，旧配置沿用收回行为。

Windows x64 安装包：`Hermes.Surface.Dev_1.7.0_x64-setup.exe`。下载后可用随附的 `SHA256SUMS.txt` 校验。安装包未签名；本次未提供 macOS 安装包。

**验收状态**：类型检查、定向测试和 Windows NSIS 构建通过；胶囊拼接动画、跨窗口预览、中文输入、混合 DPI、锁定与桌面附着的快捷键以及外部 Markdown 冲突仍需人工 GUI 验证。详见 [1.7.0 人工验收清单](MANUAL_ACCEPTANCE.md)。
