## 主要变化

- 内部保存采用原子替换和版本检查，旧窗口不能覆盖较新的笔记；分类移动拒绝目标冲突，数据目录迁移拒绝非空目标。
- 外部 Markdown 保留绑定身份、BOM、换行与权限位，保存前核对 revision；窗口草稿按顺序写入，不同窗口的冲突草稿保留恢复副本。
- Mac 显式退出等待编辑器和设置保存；保存失败保留窗口。关闭、锁定与异步刷新补充草稿保护。
- 小组件待办校验原快照，发布批量读取内部索引；发布失败有限退避重试，操作队列减少文件属性读取。
- Markdown 高亮缓存有容量上限，失效 Mermaid 请求跳过渲染；外部原子保存临时文件不再触发全目录扫描。
- 桌面折射在隐藏、暂停与睡眠时停止无效采集，停止后释放纹理缓存；屏幕变化改用通知。

## 验证范围与使用限制

自动回归、平台构建和包静态检查通过。小组件微基准没有证明速度提升；实际长期 CPU、内存、GPU、能耗，以及升级、睡眠唤醒和关键交互尚未完成本轮验收。用户已要求在这些限制保留的情况下先打包与合并，不能将此版本标作全部验收完成。

包采用 ad-hoc 签名，无 Developer ID 公证；不保证跨版本免授权或所有电脑直接运行。正文与索引不是跨文件事务，外部同步软件的并发竞争仍有剩余窗口。先向少量同学分发并验证目标机器，再扩大范围。
