## 第一批代码修复

- 内部正文改为同目录临时写入、fsync、原子替换，失败清理临时文件并保留原文；主窗、便签与胶囊待办提交加载时的更新时间，拒绝旧版本覆盖。Mac 分类操作进入同一写锁，分类路径不能越出笔记目录。
- 便签保存排队，避免新便签多次创建；复制不再清除未保存状态。主窗后台刷新保留保存失败的草稿；关闭便签先完成保存，失败留窗。
- Mac 显式退出由独立生命周期模块等待内部和外部文档窗口保存，失败/超时取消退出；不把胶囊装饰窗当作编辑器等待。
- 外部 Markdown 保留既有 revision 检查、BOM/CRLF 与绑定身份；原子替换保留文件权限位。文件缺失不会以空内容或新文件补写；较旧保存完成不能清除较新的本地草稿。显式“载入磁盘”仅清除对应草稿内容。
- 外部文件刷新在保存进行中保留编辑器；旧的无绑定文本入口也改为原子保存和内容版本检查。覆盖冲突的异步回调不能更新已切换到其他文件的窗口状态。
- 文件监听队列限制为 256，溢出触发重新核对；忽略读取事件、按内容 revision 去重；目录替换/重新出现后重挂监听，避免递归监听被单文件绑定降级。仍需真实同步盘断连/恢复验收。
- 正式小组件使用 `folio` 链接；旧 App Intent 必须匹配原快照，不能仅凭相同行文本重定位。Rust 和 Swift 围栏匹配标记与长度；拒绝快照外的行，撤销共享与写回使用同一顺序边界。
- 原生材质在主线程调用时直接执行，避免投递到主线程后阻塞等待自身。屏幕变化改用 AppKit 通知，移除两秒后台查询；已暂停的折射视图不再请求屏幕采集。
