## 历史复核与修复（2026-10-25）

本轮复核发现并修复两处竞态：

- 绑定文件重新加载时，清理草稿失败曾导致旧正文配上外部文件的新版本号，再次保存可能覆盖外部修改。现在清理成功后才一起提交正文和版本；失败保留原冲突版本，重试加载成功后才采用新版本。
- 退出或更新取消后，仍在等待载入、图片或保存队列的旧任务曾可能重新冻结输入。现在取消、新请求和组件卸载都会使旧任务失效；异步等待结束后核对任务有效性，不继续冻结、保存或发送过期准备回执。

新增 6 项回归覆盖加载失败后的版本保护及重试、取消后图片完成/失败、新旧准备请求交接、载入等待和保存队列等待。另修正 Markdown 测试在语法树尚未解析完成时提前断言的问题。综合 Markdown 样例加入 `.oxfmtrc.json` 的单文件忽略范围，保留其刻意使用的语法及硬换行。

## 覆盖审计与新增修复

原有分类样例及自动测试覆盖了常见格式、坐标、任务事务和保存生命周期，但缺少完整长文的跨面板/模式组合，也缺少引用式图片、折叠链接、波浪线 Mermaid 和打包后的 SVG 样式验证。本轮新增综合样例、真实面板组合测试及开发测试页，并发现、修复以下问题：

1. **混合/原位编辑中的引用式图片不显示**：图片片段缺少引用定义，现传入当前文档定义，定义变化及撤销也会刷新图片。
2. **引用式链接残留 `[id]` / `[]`**：非活动预览范围同步隐藏引用标签。
3. **波浪线围栏 Mermaid 被当普通代码**：局部呈现识别反引号和波浪线围栏。
4. **浏览器正常，安装版 Mermaid 尺寸和样式异常**：生成 SVG 沿用页面现有 style nonce，插入后通过 CSSOM 恢复布局样式；未放宽 CSP。安装版主窗口和桌面便签均已复查图表。
5. **Frontmatter 被误认为 Setext 标题**：元数据范围不套用 Markdown 呈现，并覆盖默认语法高亮的标题字重/下划线。
6. **混合模式复杂内容只显示源码**：统一渲染行内/块级公式、两类 Mermaid 围栏、分割线、表格及五类提示块；编辑仅展开对应范围。表格和提示块同时携带引用定义，提示块内的任务沿用现有保存/锁定/撤销路径。
7. **点击渲染表格却在块末尾输入**：widget 已计算单元格源码位置，外层进入编辑时重复做粗略坐标命中覆盖了它。现在沿用 widget 的映射位置，并对表格/公式补回归；浏览器确认桌面与胶囊都写入所点单元格，支持保存与撤销。
