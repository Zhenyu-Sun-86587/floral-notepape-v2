# P8 Windows 收尾：1.6.0

## 本轮交付

- 收纳色条支持鼠标拖动，松手吸附最近的左、右或顶部屏边。单击仍展开，悬停仍预览；Esc 取消拖动。拖放可跨显示器，保存目标显示器及沿边相对位置，不改动展开便签的坐标和尺寸。
- 同一显示器同一边共用一个轻量轨道：拖动某个色条迁移对应便签，落入已有轨道时合并并调整该轨道位置；不增加每张色条一个 WebView 的开销。排序仍按标题，不提供拖动重排。
- 普通/置顶便签在关闭 Acrylic 时也保留 Windows 系统阴影。桌面附着使用窗口内部 6px 透明留白承载轻微 CSS 阴影，不启用造成黑边的 Explorer 子窗口 DWM 阴影。读写切换保留窗口尺寸。
- Windows 原生 Acrylic 聚焦/失焦行为保持系统默认；锁定后仅现有锁图标位置可解锁，其余区域穿透；阅读正文仍为普通箭头。

## 项目复查与性能改动

| 路径           | 复查结论 / 处理                                                                                                                                                                          |

## 资源记录方法

安装包、Release EXE 与安装后目录体积分开记录；最终数值见本文件末尾。安装包不内嵌完整 WebView2 Runtime，缺少 Runtime 时按 Tauri Windows 安装逻辑处理。

本轮进程查询被当前运行环境拒绝，未取得可信 Working Set、Private Bytes 或 CPU 样本。0/1/3 张便签、3 张收纳、主界面关闭、完整退出、十次开关、首开/后续可操作延迟均保留“未测”。不得将包体积变化说成运行内存改善。

人工摆好场景后，可选用以下只读脚本采集 3 次进程快照；无须为收尾额外执行全部场景：

```powershell
$ErrorActionPreference = 'Stop'
pwsh -File "./scripts/measure-surface-resources.ps1" -Scenario "3张全部收纳" |
  Set-Content -LiteralPath "./resources-stored.json" -Encoding UTF8
```

脚本仅统计 Hermes 主进程和经父子树及独立 user-data-dir 核对的 WebView2；不能核对时 `Complete=false`。Working Set 求和含共享页，不是独占物理内存；Private Bytes 分列。CPU 是累计秒数，按同一 PID 的两次快照时间差计算，不能将不同 PID 的累计值直接比较。窗口数、首开延迟仍需人工记录。

## 本轮最短 GUI 复核

1. 色条单击展开；分别拖至左、右、上及另一显示器，松手后贴边；退出重开保留收纳位置，展开便签仍回原尺寸/位置。
2. 拖动按 Esc 能取消；预览跨到卡片不闪，应用可正常退出。
3. 白色背景上确认普通/置顶和桌面附着便签的轻微阴影；桌面模式无黑边；读写和锁定切换后锁按钮仍对齐。
