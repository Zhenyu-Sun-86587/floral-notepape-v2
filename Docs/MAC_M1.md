# Mac M1：阅读、外观与锁定安全修复 — 1.7.12

日期：2026-10-02。基于 Mac M0 1.7.11。用户确认固定与取消交互正常；其余 M0 项不能据此全部标为通过。

## 本阶段变更

- 移除 Tile 中四个内侧直角装饰角标；这些角标与用户截图中的内侧线条对应。动态窗口显式使用透明原生/WebView 底色，保留原有圆角、正文与轻微阴影。实际圆角外缘是否还有底板仍待截图复测。
- Mac 新配置默认渲染 Markdown，旧 Mac 配置首次升级时开启一次，并记录 `.macos-markdown-default-v1`。之后尊重设置中的渲染开关，编辑态仍是源码，不修改 Markdown 文件内容。
- 接入 Tauri 原生 AppKit UnderWindowBackground 材质和圆角参数，遵从系统聚焦/失焦策略；用户可在外观设置中启用。没有用 CSS 背景模糊代替原生材质。
- 提前补齐 M2 的锁定安全缺口：原生 NSPanel + NSView 绘制原闭锁路径，覆盖原图标的 DOM 热区。正文穿透，解锁仅接收小热区点击，不新建 WebView，也不使用全局鼠标监听。
- 原生对象操作在主线程，点击后的会话更新在工作线程；CSS 坐标经过 NSView/NSWindow 换算到屏幕，避免全屏 Y 翻转和重复 Retina 缩放。覆盖层作为便签子窗口跟随移动、隐藏和 Spaces，解锁/销毁时清理；没有可用热区时不先令主体穿透。

## 用户复测

1. 打开原来的 Today 便签，确认阅读态标题、引用、任务和代码渲染；点击正文仍可编辑源码，返回阅读后继续渲染。
2. 浅/深背景下检查四角，尤其截图中的左上角和右上角，确认无内侧直角角标、白色矩形底板或黑边。
3. 开启外观设置中的原生材质，确认磨砂与透明度、文字可读性、失焦后视觉；没有通过前不要记录视觉验收通过。
4. 锁定 → 点击正文位置应操作下方应用 → 点击原锁图标位置解锁，连续三次；再检查移动/缩放后锁定及普通/置顶模式恢复。
5. 关闭/收纳/全局隐藏时确认原生解锁入口一起消失，没有残留可点小窗口；恢复后能解锁。

## 安装与后续

用户授权此后每阶段自行退出或 kill 旧进程、替换安装新版并清理旧安装包；保留笔记、外部 Markdown 和配置。每阶段仍构建新包并推送 GitHub。开发包仅 arm64，无 Developer ID 签名/公证。

M2 尚需菜单栏驻留、静默焦点和桌面层等行为；M3 尚需 Mac 原生胶囊拖动、跨屏和菜单栏/Dock 安全边缘。胶囊已有共享收纳与预览代码，但没有宣称完整 Mac 胶囊验收通过。
