# Mac 1.8.4：小组件旧快照与旧打开入口修复

用户在交互测试版中仍看不到复制按钮，点击仍展开便签。磁盘扩展有新Intent元数据不代表系统已经刷新小组件视图；此前多个构建重复使用1.8.3，且相同notes.json被去重，启动时没有主动请求刷新。

本次将主应用、扩展的显示版本与构建版本更新为1.8.4；主应用初始化时请求FolioNote时间线刷新一次，日常内容发布继续去重。删除Rust中的旧URL打开便签逻辑，原生Apple Event处理器消费历史小组件链接，避免旧快照继续展开便签。不重置系统WidgetKit或后台活动数据库，不删除笔记和小组件配置。

安装后核对主应用、扩展、PlugInKit路径与版本一致。人工仍需确认复制按钮实际出现、字号选择、翻页及复制粘贴、点击不展开。系统时间线刷新不是即时保证；如桌面仍为旧视图，只移除并重新添加笺影小组件。构建成功和磁盘元数据检查不等于这项人工验证已通过。

仍使用本机免费开发授权，个人测试包不作为通用分发包。Windows运行实现不变，共用发布版本更新为1.8.4。
