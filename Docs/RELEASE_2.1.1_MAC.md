# 笺影 Mac 2.1.1：编辑入口与设置清理、正文顶部间距

基线 main `0886765` / 2.1.0。本轮按实际源码核对 PR #26 的演变：`d91e713` 撤回胶囊预览编辑会话，`a1a0474` 移除胶囊预览编辑器，最终悬停预览仅渲染 Markdown。2.1.0 的“原位编辑”开关实际控制桌面便签，容易与已撤回的预览实验混淆。

## 编辑入口与设置

- 移除 Mac 的“原位编辑”开关及相关前端分支，桌面便签统一在当前窗口编辑。旧配置字段仅保留兼容，不再控制行为；不恢复胶囊预览编辑。
- 保留“双击文字区域进入编辑”作为唯一入口设置：开启则先阅读、双击正文编辑；关闭则打开便签默认可编辑。设置变更应用到已打开的便签，显式编辑按钮仍可使用，确认保存可退出编辑。
- 锁定便签不自动进入编辑，后台静默恢复只准备编辑状态，不主动切换原生窗口层级或激活各窗口；Windows 原有路径保持。
- 原位编辑不再覆盖双击手势优先级；源码／混合／预览三种显示与 2.1.0 的缓存、按需渲染、保存屏障保留。
- 核对其他开关：自动保存、保存后回到磁贴、记住尺寸、HTML、远程图片、分栏同步、Ctrl+右键和原生材质均存在实际调用，保留；Mac 已由三模式替代的旧磁贴 Markdown 开关继续不显示。没有根据名称批量删除有效功能或重置用户配置。

## 正文间距

仅调整启用原生标题栏的 Mac 桌面便签：正文顶部内边距由 16px 降到 6px，首个 Markdown 标题去掉额外上间距；后续标题段落间距保留。原生 AppKit 48pt 标题区域、窗口尺寸和几何保存逻辑不变。没有裁剪正文、删除笔记开头空行或改写 Markdown；本机 Today 源文件无开头空行。

## 验证与交付边界

本地 TypeScript、oxlint 和前端生产构建通过；45 文件／201 项前端测试通过，含默认编辑／双击阅读／锁定、实时设置切换、静默恢复不激活，以及设置界面清理回归。测试桩不能证明真实鼠标双击、输入法和像素间距，界面效果继续由用户人工验收。本轮不做 computer use，不新增性能百分比结论。

完整 Xcode 主应用及 WidgetKit 构建、安装、发布结果随后补记。沿用 ad-hoc 签名，最低 macOS 15；超大竖排需 macOS 27。2.1.0 的小组件授权用户已选择稍后更新，本轮不自动授予权限或再次要求立即操作。自动 CI 保持关闭，仅手动构建。test-app 不改造。
