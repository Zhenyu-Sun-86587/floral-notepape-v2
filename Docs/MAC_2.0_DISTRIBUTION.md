# 笺影 2.0 macOS 运行与有限分发

2.0.0 已按用户要求进入打包与合并阶段，安装、升级及跨电脑授权验收尚未完成。审计证据见 [MAC_HARDENING_2.0.md](MAC_HARDENING_2.0.md)。

## 安装与升级

- 本轮包为 Apple Silicon，构建最低系统版本为 macOS 15；实际审查机器为 macOS 26.7.1。其他系统版本未验证。
- 主应用固定为 `/Applications/Folio.app`，显示名「笺影」，身份 `dev.hermes.surface`。升级前完成内部与外部笔记保存，从应用菜单正常退出，再替换主应用。
- 保留现有配置、数据目录、外部文件与共享选择。不要删除 Library 下的应用数据或正式小组件容器来处理升级问题。
- 核对安装包 SHA-256 和对应源码提交。出现保存冲突时保留或复制草稿，再核对最新正文；不要反复强制覆盖。

## 授权与小组件

该包使用 ad-hoc 签名，没有 Developer ID 公证。签名完整性校验不等于 Gatekeeper 信任，也不保证其他电脑能直接运行。遇到系统阻止时由使用者通过系统提供的界面处理；本项目不自动移除隔离属性、修改安全数据库或绕过保护。

小组件只读取主程序发布的已选笔记快照，支持内部便签和绑定的外部 Markdown；不直接获得整个笔记库。快照位于扩展自己的私有容器，不依赖 App Group。首次添加、更新签名或权限拒绝后可能需要重新授权或重启主程序；没有「永久免授权」保证。主程序退出后，小组件可显示最后发布内容，原文件新改动需主程序运行后发布。

待办操作要求原快照仍匹配；过期操作会被拒绝。发布失败有有限退避重试，超过重试窗口可在权限恢复后重新选择共享或重启应用。

桌面折射需要屏幕录制权限，拒绝时保留原生材质回退。节能档降低采集帧率和便签渲染分辨率，具体代码预算见审计文档；未测量实际能耗降幅。

## 分发前人工验收

1. 先在有备份的测试笔记上核对内部与外部编辑、冲突、删除原文件后恢复、退出再打开。
2. 核对材质反复切换、锁定与解锁、胶囊合并分离、全屏与 Spaces。
3. 核对小组件首次添加、翻页、待办、主程序退出时操作，以及升级和重启后的授权。
4. 至少另一台目标 Mac 验证首次安装与权限拒绝后的恢复，再扩大分发。

原子替换不构成正文和索引的跨文件事务，也不能完全排除外部同步软件同时写入的竞争。定期备份仍必要。未通过上述链路和实际长期性能验证前，不标记为全面完成。
