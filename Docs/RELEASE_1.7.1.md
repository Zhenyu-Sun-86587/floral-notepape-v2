# Hermes Surface Dev 1.7.1

本次 Windows 版本修正胶囊颜色与展开状态，并改进合并组的拖动和布局动画。

- 不同便签首次收纳时取得持久颜色；展开、隐藏和重启不重新分配，删除便签后颜色可供新便签使用。色板扩至 12 种低饱和颜色。
- 展开便签时胶囊留在边缘，以凸起与高亮显示；点击它可定位便签。收回时胶囊直接恢复普通外观。
- 合并组有独立拖动头，Windows 上可带着所有成员一起移动或换边；单个成员仍可独立拖出。
- 合并、拆分和关闭成员后，已有胶囊小窗按时间补间到新位置，避免瞬间跳位；拖动过程中不逐帧写入磁盘。

Windows x64 安装包：`Hermes.Surface.Dev_1.7.1_x64-setup.exe`；随附 `SHA256SUMS.txt`。安装包未签名，本次没有 Mac 安装包。

**验收状态**：类型检查、定向测试与 Windows NSIS 构建完成；颜色观感、组拖动、多显示器与混合 DPI、展开标记及实际动画流畅度仍需用户 GUI 验证。详见 [人工验收清单](MANUAL_ACCEPTANCE.md)。
