# 笺影 Mac 2.0.1：主应用配置小组件

小组件显示哪篇笔记、使用哪个字号，改由笺影主应用设置。提供「笺影便签 1」至「笺影便签 4」四种系统 WidgetKit 组件；内部便签与外部 Markdown 均可分配，同一编号的多个副本共享内容及字号，尺寸仍由系统管理。

## 使用与升级

1. 在笺影设置中勾选允许共享的笔记。
2. 为便签 1–4 选择内容和字号。
3. 右键桌面 → 编辑小组件，添加对应的「笺影便签 N」。多个不同内容需使用不同编号。

原先在系统编辑面板中的笔记/字号选择不再使用。主程序不会按快照顺序猜测原配置：升级初始四个编号未分配，需在主应用选择一次。撤销共享或笔记不可读取时，组件显示配置提示，不替换为其他笔记。旧组件若仍显示系统缓存，请只移除该笺影组件并重新添加，不重置系统数据库。

正式应用 Bundle ID、扩展 ID、配置与笔记身份保持不变。原共享许可文件保留；编号配置独立保存于既有配置目录的 widget-displays.json，按单个编号加锁、原子写入。App Intents 继续用于翻页、复制、待办；不把本机配置读取失败扩大成「所有 ad-hoc App Intents 不可用」。

切换后旧按钮核对当前编号的笔记 ID；待办队列写回时主程序再次核对，拒绝切换后的旧操作。保留完整正文/原始待办行和 revision 检查。翻页按编号、笔记、尺寸、字号隔离。
