# Mac 1.7.11：M0 独立便签首次显示修复

用户人工反馈：1.7.10 基础使用大体正常，但点击图钉没有出现独立便签。这是 M0 缺陷，不能据此进入 M1。

## 原因与修改

原生窗口以 visible(false) 创建；NotePad 首次显示依赖嵌套的两次 requestAnimationFrame。WebKit 在非活动页面会停止动画帧，使隐藏窗口的显示请求可能永远无法执行。参考 [WebKit 官方说明](https://webkit.org/blog/8970/how-web-content-can-affect-power-usage/)。这是源码与平台行为确认的显示链路缺陷，真实 Mac 图钉复现/修复结果仍需用户复测。

改为配置/正文 bootstrap 完成后由 React effect 直接启动显示，普通打开与静默恢复均不等待动画帧。保留桌面模式/锁定的无焦点显示分支、待机窗口隐藏及异步取消保护；显示失败不再吞掉错误。
