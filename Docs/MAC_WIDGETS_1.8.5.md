# Mac 1.8.5：小组件显式展开按钮

用户已确认1.8.4复制按钮出现、点击不展开便签。本版仅在小组件标题右侧增加“展开便签”箭头按钮。正文、标题、底部复制按钮与空白继续使用原有复制/不打开行为，不设置全局widgetURL。

展开按钮使用AppIntent返回OpenURLIntent，走专用`folio://widget-open/{note|linked}/{uuid}`入口；原生事件处理器继续消费旧`folio://note/...`链接而不打开。扩展与主应用均检查便签仍被允许共享，主应用校验UUID及类型后才打开对应内部或外部便签。避免恢复已废弃的整块点击入口。

本版独立版本号1.8.5，安装时结束本项目主应用/小组件旧进程，登记新扩展并由主应用启动请求一次刷新。不改Windows运行逻辑，不迁移笔记。本机免费开发授权期限不变，仍为个人测试包。

人工检查：点击标题右侧箭头展开对应便签；关闭后点正文/标题复制而不展开；检查底部复制、翻页与字号继续可用。构建、签名和进程版本核对不能替代这些人工检查。

基础验证：Swift类型检查、仅专用URL可展开的Rust测试、Mac应用构建与云端WidgetKit构建通过（run 37046933629）。已安装1.8.5并结束旧扩展进程，主应用/扩展版本与系统登记一致，运行扩展映射来自安装目录。个人DMG签名、版本一致性检查通过，Markdown内容哈希未变。展开按钮最终交互仍待人工检查。
