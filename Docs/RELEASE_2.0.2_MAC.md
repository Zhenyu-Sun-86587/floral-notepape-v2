# 笺影 Mac 2.0.2：退出保存确认修复

基线 main `e758775`，本机安装 2.0.1。用户反馈频繁出现「等待笔记保存超时，已取消退出」。静态审计确认：Mac 退出广播 `update://prepare-install`，主窗与内部/外部便签保存后调用 `update_install_prepare_report`，但该命令未注册到主应用 IPC 列表。保存完成或失败都无法回报，退出会话因此一直等待，直至 20 秒超时。

恢复保存确认命令的注册，不恢复自动更新、下载安装或 CDK 功能。通知发送失败立即记录失败，失效的保存会话明确取消退出。保留全部文档窗口（包括隐藏窗口）的保存确认，保存失败或真实超时仍取消退出；没有通过强制退出、忽略外部笔记或延长超时掩盖问题。

新增独立 Node 跨语言注册检查，防止只 mock invoke 却漏掉 Rust 命令的情况；不把 Node 文件 API 引入前端或增加类型依赖。本机检查通过，并在旧基线上正确检出遗漏；前端定向 5 项、Rust 保存准备状态定向 3 项及 TypeScript 检查通过，覆盖完成/失败、新建/已关闭窗口及超时边界。

修改不迁移笔记或配置，小组件编号设置与共享许可沿用 2.0.1。安装前已备份并校验真实内部/外部笔记、配置、绑定、共享许可及旧完整应用，私人备份不随包分发。
