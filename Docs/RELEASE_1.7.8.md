# Hermes Surface 1.7.8 — 编辑区符号显示与首行位置

- 用户对比图显示阅读态保留完整问号串，编辑态部分字符不可见；本机外观配置使用 Maple Mono NF CN。源码编辑区关闭 liga、clig、dlig、calt 连字，让连续符号独立显示，保留所选字体。
- 标题输入框改为块级布局，消除编辑态内联输入框产生的基线留白，保持读写态相同的标题下间距。
- 空白便签进入编辑时清除旧滚动锚点，将光标与滚动位置复位到正文首行；已有正文仍保持点击定位和选区。

未引入输入拦截、正文替换或依赖升级。连字是依据配置和截图选择的修复方向，尚未在用户 WebView/字体环境中验证，因此不将根因与显示修复宣称为已实测确认。

5 项 MarkdownSurface 定向测试、lint、TypeScript/Vite 生产构建及 Windows x64 NSIS 打包通过。自动测试覆盖首行定位与既有选区、撤销、任务写回及组合输入保护，不验证真实字体绘制。

安装包：Hermes Surface Dev_1.7.8_x64-setup.exe。

人工验收见 [MANUAL_ACCEPTANCE](MANUAL_ACCEPTANCE.md)；Mac 未实测。

## 胶囊切换与同步文件读取

- 再次单击已展开的胶囊会请求便签先保存再收回；鼠标实际拖动仍走原拖动流程，键盘激活也支持切换。保存失败保留窗口，组合输入期间不销毁窗口。
- 外部文件读取对 NotFound 和 Windows 共享/锁定冲突最多重试三次（100、200、400ms）；持续失败包含路径与原始原因。没有重试写入或降低 revision 冲突保护，缺失文件不会按空白正文覆盖。
- 去掉展开入口一次重复全文读取。同步工具替换文件期间的短暂缺失是代码确认存在的触发路径，但尚无用户报错日志证明具体由同步服务器引起。

6 项外部文件定向测试通过，覆盖读取重试、永久错误停止、版本冲突、换行/BOM 保留和同步临时文件排除。
