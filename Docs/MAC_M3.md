# Mac M3 与编辑性能优化 — 1.7.14

日期：2026-10-02，基于 M2 1.7.13。用户反馈 M2 基本正常，但便签编辑卡顿；本次按用户要求先优化编辑，再接续 M3，合并构建后一起人工测试。

## 编辑优化

SourceEditor 每次收到本地输入回传都会对全文执行 toText().toString()，中文 composition 结束还会重建语法扩展和派发只读配置。现在缓存 EditorState 最新正文快照，本地回传直接跳过重复规范化；外部正文仍做最小差异更新并保留历史。Markdown 扩展复用，语言和只读状态只有实际改变时才重新配置，候选输入期间仍延迟外部正文和模式变化。

长文测试包含 2,000 行中文 Markdown 和 20 次连续输入：本地回传不再调用全文规范化；外部换行更新仍正确写入，撤销保留外部更新和常驻 EditorView。这是重复工作的减少证据，不是 WebKit 实机延迟基准；实际中文输入、滚动和长文手感待用户验收。

## M3 收纳对齐

- Mac 接入胶囊单成员拖出、整组拖动和拖放停靠；4 逻辑像素阈值区分单击与拖动，鼠标释放结束，Esc/超时/错误恢复已保存位置。拖动期间才采样当前鼠标/按键状态，不安装事件 tap。
- Quartz 光标使用全局逻辑坐标，目标显示器单独换算缩放；AppKit 主线程移动窗口。保留展开便签的独立位置，拖动胶囊只改收纳位置、边缘和显示器。
- 修补现有 Wry 0.55.1 的 Mac 创建路径，使其遵守 focused(false)，避免隐藏胶囊、预览、预热或动态便签创建时无条件激活应用。补丁源码与许可证随仓库保存，说明见 [WRY_PATCH](../src-tauri/vendor/WRY_PATCH.md)，配套修补现有 Tao 0.35.3，静默启动策略改在事件循环启动前设置并跳过底层激活请求；没有升级依赖版本。显式显示和编辑仍由后续聚焦入口处理。
- 原组保持可见，新组 ready 后，在同一次 AppKit 主线程交接中显示新组再退役旧组。支持隐藏备用窗口复用；不宣称与 Windows DeferWindowPos 等同的系统原子事务。
- Mac 胶囊顶部放在工作区顶部，即菜单栏/刘海下方；左右使用工作区边缘，避开已占用的 Dock。预览同样按工作区夹紧，并按目标屏幕缩放定位；顶部预览避开轨道本身。
- 每两秒比较显示器与工作区几何，仅变化时重排，适配插拔屏幕、缩放与 Dock 工作区变化；拖动中的重排由既有互斥/恢复流程处理。
- Mac 预览补鼠标释放兜底与一致坐标，避免窗外松键后一直保持选择占用。共享快捷键、单击展开/再次收回、右键菜单、预览任务写回和持久恢复继续沿用原协议。

接口依据：[Apple 鼠标位置](https://developer.apple.com/documentation/coregraphics/cgevent/location?language=objc)、[按钮状态](https://developer.apple.com/documentation/coregraphics/cgeventsource/buttonstate%28_%3Abutton%3A%29)、[工作区排除菜单栏和 Dock](https://developer.apple.com/documentation/appkit/nsscreen/visibleframe?changes=l__3__8&language=objc)。自动隐藏的菜单栏/Dock、Spaces 和 Stage Manager 的真实交互仍需人工确认。

## 一起人工检查

1. 原来会卡的便签，连续中文输入、删除、回车、滚动；再试较长 Markdown。Cmd+Z 撤销，切回阅读、保存和重开，确认内容、光标与 Markdown 正常。若仍卡，记录是在输入、滚动、刚进入编辑还是保存时。
2. 收纳至少三张便签，胶囊单击展开/再次收回；拖单个胶囊移动到左/右/顶边，靠近其他胶囊合并，拖单成员拆出，再拖组头整体移动。Esc 取消后不能留下空白拦截窗或丢入口。
3. 顶边应在菜单栏下方；Dock 在左/右/下以及自动隐藏时检查可点击性。胶囊悬停预览、任务勾选、选择后在窗口外松键、右键编辑/关闭；预览不应一直悬挂或挡住入口。
4. 有外接屏时，拖胶囊到另一屏及不同缩放/负坐标位置，再插拔或调整排列，检查最终成员完整、位置与文字大小；至少等两秒让几何重排完成。
5. 退出重开、全局隐藏/显示、已有快捷键，再检查胶囊位置/边缘恢复，以及 M2 桌面层与锁定未退化。

M4 为 Mac 发布收尾与验收问题修复；本阶段不将手动交互项目标为通过。
