# 笺影 Mac 1.8.9：材质切换保留内容视图

用户报告从 Mac 原生材质切换后，主窗口只剩透明背景，正文与设置消失。原实现把主窗口的 Wry 根视图作为 NSGlassEffectView 的 contentView，切换时拆下再挂载。玻璃视图会管理内容的尺寸与生命周期，这条路径存在内容脱离和布局失效风险。

本轮统一为固定内容层和独立材质层：Wry 根视图始终挂在同一个裁剪容器内，玻璃只拥有空的装饰内容视图。玻璃和磨砂视图明确插入正文下面，切换仅删除旧材质层；重新同步根视图尺寸并请求布局。关闭材质后仍由原有主题 CSS 提供背景。没有新增轮询、屏幕采集或动画，也没有修改 Windows 实现。
