# Mac 1.7.21：紧凑泡泡与鼠标事件修复

针对 1.7.20 的直接点击、拖动、桌面点击穿透和预览交互材质变化问题，修正 Mac 原生胶囊链路。上一版辅助功能按钮检查绕过了真实鼠标事件，本轮使用鼠标坐标点击和拖动检查。

## 外形与事件

- 单个泡泡 40 点；常见双成员组为 68 × 44 点。多个成员紧凑排列，背景由重叠的原生玻璃形状融合，不使用长条或固定大圆盘。文档图标浮在共同背景上，删除可见的拖动头。
- 拖动图标拆出单张，拖动内部空白移动整组。单个泡泡整个区域可以点击；松键且未拖动才展开/收回，拖动阈值为 4 点。
- 按下位置读取 NSEvent 自身坐标，避免工作线程启动时鼠标已移动或松开，丢失起始位置。布局复用按 Mac 泡泡尺寸核对，普通状态更新不重新创建窗口。
- 胶囊不成为键盘主窗口，明确接收鼠标事件，按钮无需激活面板；融合动画不再把真实入口设为完全透明，避免点击落到 Finder/台前调度的桌面。
- 悬停预览的玻璃背景与可选择正文分开，交互不把正文纳入玻璃控件强调层。预览放在泡泡窗口外侧，避免覆盖点击目标。

## 性能边界

形状通过 NSGlassEffectContainerView 合成，布局只在成员或配置变化时计算。空闲时不运行物理模拟；拖动期间保留现有 16ms 采样。这里没有持续流动、拉丝或逐帧物理回弹。若未来采用这些效果，应先向用户说明复杂度与性能代价。未做性能基准测试。

Windows 通过编译选择保留原几何、鼠标和渲染实现。共享拖动入口新增可选按下位置，Windows 仍使用原来的实时起点。

## 基础验证

泡泡布局 2 项、胶囊相关 Rust 检查 16 项、Mac 预览组件 2 项通过；lint 和 Windows 前端构建通过。Windows 原有胶囊组件没有修改。Mac 安装包构建通过，隔离数据下确认原生小泡泡窗口正常显示。

真实坐标点击曾验证一次展开及再次收回；最终缩小版的拖动自动检查遇到系统窗口命中限制，未完成真实拖拽验收。辅助功能按钮检查不代替鼠标验收。预览材质、快速拆分/融合以及台前调度点击行为保留人工复测，不宣称已全部修复。

## 人工复测重点

1. 在其他应用前台直接点击泡泡，一次展开、再次收回；不先悬停。检查桌面和台前调度没有跟随切换。
2. 拖动图标拆出并融合，拖动空白移动整组；快速拖动、跨边缘、切换桌面。
3. 悬停预览后点击正文、选择文字，材质应保持一致，内部不出现灰色矩形；切换玻璃/磨砂检查整个背景。
4. 检查小尺寸无定形泡泡的通透度、边界和图标间距。视觉效果与台前调度仍需要用户人工验收。
